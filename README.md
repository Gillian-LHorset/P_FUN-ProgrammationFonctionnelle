# P_FUN-ProgrammationFonctionnelle

## temperature.db

Le projet tourne grâce à une base de données SQLite. Cette base de donnée se copie automatiquement lors du lancement du debug.

Cela peut être changer en allant dans l'explorateur de solution de Visual Studio en cliquant sur le fichier temperature.db --> propriété et en changant la valeur de la ligne `Copier dans le répertoire de sortie`.
